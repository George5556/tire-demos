# Хороший шиномонтаж — лендинг

Одностраничный сайт шиномонтажа на Комендантском проспекте, 44к2 (Санкт-Петербург).

## Файлы

- `index.html` — вся разметка, стили интерфейса и логика.
- `styles.css` — сгенерированный и минифицированный Tailwind CSS (подключается вместо CDN).
- `src/input.css` — исходник для сборки CSS.
- `tailwind.config.js` — конфиг Tailwind (цвета `ink`, `card`, `acc`).
- `package.json` — скрипты сборки.

## Сборка CSS

После правки классов в `index.html` пересоберите стили:

```bash
npm install
npm run build:css
```

Готовый `styles.css` уже лежит в проекте, поэтому для публикации достаточно загрузить
`index.html` и `styles.css` — сборка на сервере не нужна.
